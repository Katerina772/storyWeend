# Worldbuilding Platform

Вебплатформа для візуального проєктування та організації вигаданих світів.

## Стек

- Frontend: React + React Router
- Backend: Node.js + Express
- База даних: PostgreSQL
- AI-модуль: Python + FastAPI (окремо)

## Структура

- `client/` — React-застосунок
- `server/` — Node.js API
- `ai-service/` — Python AI-модуль (РГР)
- `docs/` — документація
